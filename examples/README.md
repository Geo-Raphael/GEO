# Exemplos e casos de uso

Espaço para reunir exemplos práticos de uso do QGIS MCP aplicados ao contexto de saneamento e recursos hídricos da DAE Jundiaí. Ainda vazio — a preencher conforme os testes avançarem.

Ideias de casos de uso a prototipar:

- Validação topológica de redes de água/esgoto via comandos disparados por um agente de IA
- Geração automática de mapas temáticos (bacias, UCs, áreas de influência) a partir de descrições em linguagem natural
- Rotinas de cadastro técnico: carregar camada, calcular campos, aplicar simbologia padrão da empresa
- Prototipação de dashboards/relatórios visuais para apresentações internas
