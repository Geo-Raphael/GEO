# /docs

Notas de estudo, comparação entre implementações e registro de decisões para o laboratório MCP + QGIS.

## Conteúdo

- [`comparacao-mcp-qgis.md`](./comparacao-mcp-qgis.md) — comparação entre `jjsantos01/qgis_mcp` e `nkarasiak/qgis-mcp`: arquitetura, protocolo, ferramentas expostas, requisitos e licenciamento.
- [`decisoes.md`](./decisoes.md) — registro de decisões técnicas tomadas ao longo do laboratório (formato ADR-lite: contexto → decisão → consequências).

## Como usar esta pasta

- Cada nova investigação relevante (leitura de código-fonte, teste de instalação, comportamento observado) deve virar uma anotação aqui, não só ficar na memória da conversa.
- Decisões técnicas importantes (ex.: "vamos seguir com a implementação X como base", "vamos expor apenas os comandos Y e Z") devem ser registradas em `decisoes.md`, com data e motivo.
